# ChessRip
Chess Rip is a powerful software that connects with stockfish to show arrows on a chess website.

Configuration:
1. Download source code or zip from releases.
2. Paste stockfish executable (exe) to engine folder. (You can get stockfish exe by downloading newest version from https://stockfishchess.org/ and unpacking the file)
    There will be more files after unpacking file from https://stockfishchess.org/ so be aware that you NEED to paste only the executable file
3. Open run.py in notepad and change the browser to the name of your liking ("chrome", "brave", "opera", "opera_gx", "edge" albo "firefox")
4. Run file "run.py", it will open up a tab of a chess website.
5. Enjoy!

   Remember: App is still in beta so there may be errors and may not work on some devices!
